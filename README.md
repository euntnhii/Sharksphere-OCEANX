# Sharksphere: Exploring Ocean Balance Through Immersive Science  


## Project Name: Ocean Research Mission  

## Description:  
Ocean Research Mission is an experience that aims to raise awareness on predator-prey relationships and ecosystem feedback mechanisms in underwater ecosystems through AI and immersive experiences.  
This experience invites users to roleplay as a scientist and embark on a journey with an Ocean Protector. Through the journey, users get a glimpse into what it is like to be an ocean scientist, increasing their ocean literacy and deepening their understanding in the field of ocean science.  

## Flow of Experience:  
Introduction (Onboarding) -> Activity 1 -> Learning Points -> Activity 2 -> Learning Points -> Offboarding  

### Activity 1 (Shark Counting):  
-How do Ocean Scientists use technology to help with their jobs?  
-Visitors are invited to count sharks from a footage  
-AI then counts sharks from the same footage  
-Using AI to count shark populations from video footages is one way technology is used to help ocean scientists  
-Why is AI helpful in counting sharks?  
-Why do ocean scientists count sharks?  
-Why is it important for ocean scientists to have accurate shark populations?  

### Activity 2 (Model of the Sea):  
-What is the effect of different Shark populations on a reef ecosystem?  
-How does having different shark populations affect the other species within the ecosystem?  
-Visitors are brought to an ocean simulation where they can adjust shark populations within the simulation  
-Simulation state updates based on the shark population, displaying different no. of species, coral health, and anomaly score each time the shark population is changed  
-This experience shows the importance of having accurate shark populations: Scientists can understand whether an ecosystem is balanced or not based on having accurate species populations.   
-Visitors understand the importance of a balanced ecosystem from adjusting the simulation throughout different ecosystem balances  
-Visitors also learn about different ecological roles within an ecosystem and how each of them gets affected shark populations  

## Installation Guide:  

### Setting up Activity 2 (Simulation):  
#### Pre-requisites: 
Node.js (LTS version recommended), npm  

#### Installation:  
```bash
git clone https://github.com/euntnhii/Sharksphere-OCEANX.git
cd Sharksphere-OCEANX
npm install
```

#### Running the project:  
```bash
npm run dev
```

Then open the local URL displayed in the terminal (typically `http://localhost:5173`).  

#### Building  

```bash
npm run build
```

#### Previewing the production build  

```bash
npm run preview
```
